# Sai Venkata — Electrical Design Engineer Portfolio

A responsive static portfolio website with no build step or paid libraries. Files: `index.html`, `style.css`, and `script.js`.

## Before publishing
1. Confirm the experience duration and edit the copy if needed.
2. Add your actual LinkedIn profile URL in `index.html` (search for `https://www.linkedin.com/`).
3. Add a CV PDF if you want a resume download button. The current version intentionally doesn't offer a fake download link.
4. Verify project names/descriptions are approved for public disclosure by your employer/client. Keep confidential drawings and calculations off the public site.
5. Check that the contact email shown is the one you want public.

## Publish for free on Vercel (no coding required)
1. Open https://vercel.com and sign in or create an account.
2. Open https://github.com and create a new repository, e.g. `sai-venkata-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` from this folder to the repository root.
4. In Vercel, choose **Add New → Project**, import that GitHub repository, and deploy. This is a plain static site; no framework/build command is required.
5. After deployment, Vercel will provide a public `*.vercel.app` URL. Test it on your phone and share it with recruiters.

Vercel/GitHub interface wording and free-plan terms can change. Do not share your passwords or verification codes with anyone.
